# 微分方程求解器

## 概述

本求解器支持**线性常系数微分方程**的符号求解，适用于《信号与系统》和《高等数学》课程。

## 方程形式

```
aₙy⁽ⁿ⁾ + aₙ₋₁y⁽ⁿ⁻¹⁾ + ... + a₁y' + a₀y = bₘx⁽ᵐ⁾ + ... + b₁x' + b₀x
```

- 最高支持**三阶**微分方程
- 支持右侧对 `x(t)` 的微分运算

## 输入格式

### y 系数

逗号分隔，从高阶到低阶：

| 输入 | 含义 |
|------|------|
| `1,1` | y' + y |
| `1,0,1` | y'' + y |
| `1,3,2` | y'' + 3y' + 2y |
| `1,0,0,1` | y''' + y |

### x 系数

逗号分隔，从高阶到低阶：

| 输入 | 含义 |
|------|------|
| `1` | x(t) |
| `2,3` | 2x' + 3x |
| `1,0,0` | x'' |

### x(t) 表达式

支持以下内置函数：

| 符号 | 名称 | 说明 |
|------|------|------|
| `t` | 时间变量 | 默认值 |
| `u(t)` | 单位阶跃 | t<0 时为 0，t≥0 时为 1 |
| `δ(t)` | 单位冲激 | Dirac delta 函数 |
| `sin(t)` | 正弦函数 | |
| `cos(t)` | 余弦函数 | |
| `e^t` | 指数函数 | 或 `e^(αt)` 如 `e^(-t)` |
| `1` | 常数 | |

**组合示例**：
- `e^(-t)*u(t)` - 衰减阶跃
- `sin(t)*u(t)` - 因果正弦

### 初始条件

支持两种格式：

| 格式 | 说明 |
|------|------|
| `y(0)=1, y'(0)=0` | 默认（0+ 条件） |
| `y(0-)=1, y'(0-)=0` | 0- 条件（激励作用前） |
| `y(0+)=1, y'(0+)=0` | 0+ 条件（激励作用后） |

**重要**：当激励包含 `δ(t)` 或 `u(t)` 时，建议使用 `0-` 格式，求解器会自动计算 `0+` 条件。

## 显示模式

### 思路1：响应分解

适用于信号与系统分析：

1. **单位冲激响应 h(t)** - 系统对 `δ(t)` 的响应（系统固有属性）
2. **零输入响应 y_zi** - 仅由初始条件引起，输入为 0
3. **零状态响应 y_zs** - 仅由输入引起，初始条件为 0
4. **完全响应 y** - y = y_zi + y_zs（自动合并同类项）

### 思路2：解结构

适用于高等数学分析：

1. **齐次解 y_h** - 齐次方程的通解
2. **特解 y_p** - 待定系数法求解
3. **通解** - y = y_h + y_p
4. **最终解** - 代入初始条件后的解

## 求解算法

### 特征方程

对于方程 `aₙy⁽ⁿ⁾ + ... + a₀y = 0`：

1. 构造特征方程 `aₙrⁿ + ... + a₀ = 0`
2. 求根（实根、复根、重根）
3. 构造齐次解：
   - 实根 r：`C·e^(rt)`
   - 复根 α±βi：`e^(αt)·(C₁cos(βt) + C₂sin(βt))`
   - 重根 r（m 重）：`e^(rt)·(C₁ + C₂t + ... + Cₘt^(m-1))`

### 特解（待定系数法）

根据激励形式选择特解形式：

| 激励形式 | 特解形式 |
|----------|----------|
| 常数 | A |
| e^(αt) | A·e^(αt)（共振时乘 t） |
| sin(βt), cos(βt) | A·cos(βt) + B·sin(βt) |
| 多项式 | 同次多项式 |

### 冲激函数匹配法

当激励包含 `δ(t)` 或 `δ'(t)` 时，计算 `0-` 到 `0+` 的跳变：

对于方程 `aₙy⁽ⁿ⁾ + ... + a₀y = K·δ'(t) + L·δ(t)`：

1. 设 `y⁽ⁿ⁾ = A·δ'(t) + B·δ(t) + ...`
2. 匹配系数：
   - `A = K/aₙ`
   - `B = (L - aₙ₋₁·A)/aₙ`
3. 跳变：
   - `y⁽ⁿ⁻²⁾` 跳变 `A`
   - `y⁽ⁿ⁻¹⁾` 跳变 `B`

## 示例

### 例1：一阶齐次方程

```
输入：
  y 系数: 1,1
  x 系数: 1
  x(t): 0
  初始条件: y(0)=1

结果：
  特征方程: r + 1 = 0
  特征根: r = -1
  最终解: y = e^(-t)
```

### 例2：二阶齐次方程（复根）

```
输入：
  y 系数: 1,0,1
  x 系数: 1
  x(t): 0
  初始条件: y(0)=0, y'(0)=1

结果：
  特征方程: r² + 1 = 0
  特征根: r = ±i
  最终解: y = sin(t)
```

### 例3：阶跃响应

```
输入：
  y 系数: 1,3,2
  x 系数: 1
  x(t): u(t)
  初始条件: y(0-)=0, y'(0-)=0

结果：
  特征根: r = -1, -2
  h(t) = (e^(-t) - e^(-2t))·u(t)
  零状态响应 = -1.5·e^(-t) + e^(-2t) + 0.5·u(t)
```

### 例4：带 x 导数的冲激响应

```
输入：
  y 系数: 1,7,10
  x 系数: 2,3
  x(t): δ(t)
  初始条件: y(0-)=0, y'(0-)=0

结果：
  展开激励: 2·δ'(t) + 3·δ(t)
  0+ 条件: y(0+)=2, y'(0+)=-11
  h(t) = (-1/3·e^(-2t) + 7/3·e^(-5t))·u(t)
```

---

## 注意事项

1. **共振情况**：当激励的指数系数 α 是特征根时，特解需要乘以 t
2. **广义导数**：`d/dt[u(t)] = δ(t)`，`d/dt[e^(αt)·u(t)] = α·e^(αt)·u(t) + δ(t)`
3. **因果系统**：冲激响应 h(t) 自动乘以 u(t)
4. **系数合并**：完全响应会自动合并同类项
